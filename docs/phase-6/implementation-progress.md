## Проверки M01

- На исходном коде `Post_MarketGoalRestatementAndShortExperience_StartsExerciseOnResume` не находит сохранённую программу после точной реплики из плана.
- Первая проверка исправления — 13 hosted-тестов прошли с детерминированным провайдером. В набор вошли консультация, новый старт программы, общая и авторская диагностика.
- Первый полный прогон на Windows исчерпал локальные TCP-порты при выключенном пуле Npgsql. Прогон 770 unit-тестов прошёл, интеграционный результат непригоден для приёмки. Повторный прогон использует ограниченный пул.
- Повторный полный прогон с пулом — 770 unit-тестов и 451 интеграционный тест прошли, два live-теста пропущены. Выявлен лишний вызов LLM на «Продолжим» при отсутствии программы. Исправлено, что контрольная реплика возвращает к вопросу о цели без обращения к провайдеру.
- Архитектурное ревью проверило привязку к программе, сохранение вопроса при чтении прогресса и совместимость уже сохранённых контрольных отпечатков. Добавлено ограничение отката миграции для программ с записанным критерием цели.
- Последняя сборка Release прошла без предупреждений. 18 целевых интеграционных тестов прошли на PostgreSQL 17, включая английский старт, mixed-ввод, отказ планировщика, перезапуск, подтверждённую смену цели, повторы и защиту от потери критерия при откате.
- Полный прогон коммита прошёл 770 unit-тестов и 449 интеграционных. Два live-теста пропущены. Четыре теста получения lease в Inbox и Learning упали, причины уточняются на изолированном повторе.
- Язык начальных сообщений определяется исходной целью. При оценке провайдер получает указание сохранять язык материала независимо от языка ответа. Запрос объяснить на другом языке действует для текущего пояснения. Пользовательская сквозная проверка языка и качества с подключённой моделью остаётся открытой.
- Для live-качества, Telegram Desktop и NVDA требуются отдельные прогоны.

## Проверки M02

- Исходный hosted-тест ожидал второй вопрос TypeScript, но после ответа PostgreSQL по-прежнему содержал первый вопрос.
- Проверены граница пяти вопросов, запрет повторного вопроса и преждевременного вывода об уровне, отказ от результата с некорректной формой, сохранение наблюдений и вопроса при перезапуске. Поздняя диагностика по биржевым заявкам завершилась после двух ответов и сохранила версию уже начатого маршрута. Диагностика не создаёт записи mastery.
- 49 целевых интеграционных тестов на PostgreSQL 17 прошли. Набор включает изолированный повтор четырёх упавших тестов получения lease из полного прогона. Проверка педагогического выбора вопросов реальной моделью остаётся открытой.
- Существующий одиночный вопрос и авторская English-ветка читаются прежними сценариями. Новая диагностика включена для программ из консультации. Новый формат хранит исходные ответы в PostgreSQL, а планировщику передаёт текущий ответ и краткие предыдущие наблюдения. Откат миграции блокируется при наличии новых диагностических данных.

## Проверки M03

- Для новой рубрики рассчитаны отдельные пороги: два самостоятельных различных упражнения на понимание, одно самостоятельное применение, одно самостоятельное повторение по тому же навыку спустя как минимум сутки. Повтор вопроса или нормализованного ответа, помощь и неразрешённое противоречие не дают подтверждённого Mastery. Прежние записи сохраняют свою семантику.
- Hosted-сценарий TypeScript проверил публикацию критерия, сохранение исходного ответа с уточнением, восстановление после перезапуска, итоговую оценку и идентификатор операции, отсутствие дубля при повторе. Два ответа в рамках уточнения формируют одно свидетельство. Невозможность сделать вывод после уточнения сохраняется отдельно от отрицательного результата и оставляет расписание повторений без изменений.
- Архитектурное ревью выявило, что сравнение уточнения с эталоном исходного вопроса создавало бы ложный конфликт. Детерминированная проверка теперь использует исходный ответ. Адаптер отклоняет новый материал без корректной рубрики, а уже сохранённый материал остаётся читаемым.
- Release-сборка прошла без предупреждений. Прошли 776 unit-тестов и 19 целевых интеграционных проверок с PostgreSQL 17, включая старые данные, рестарт с уточнением и деградацию при отказе источника.
- Статус практической цели показывается как ожидающий прямой проверки. Сквозная проверка практической цели и экспертный набор для RU/EN/mixed остаются открытыми.
