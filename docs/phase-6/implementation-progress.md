## Проверки M01

- На исходном коде `Post_MarketGoalRestatementAndShortExperience_StartsExerciseOnResume` не находит сохранённую программу после точной реплики из плана.
- Первая проверка исправления — 13 hosted-тестов прошли с детерминированным провайдером. В набор вошли консультация, новый старт программы, общая и авторская диагностика.
- Первый полный прогон на Windows исчерпал локальные TCP-порты при выключенном пуле Npgsql. Прогон 770 unit-тестов прошёл, интеграционный результат непригоден для приёмки. Повторный прогон использует ограниченный пул.
- Повторный полный прогон с пулом — 770 unit-тестов и 451 интеграционный тест прошли, два live-теста пропущены. Выявлен лишний вызов LLM на «Продолжим» при отсутствии программы. Исправлено, что контрольная реплика возвращает к вопросу о цели без обращения к провайдеру.
- Архитектурное ревью проверило привязку к программе, сохранение вопроса при чтении прогресса и совместимость уже сохранённых контрольных отпечатков. Добавлено ограничение отката миграции для программ с записанным критерием цели.
- Последняя сборка Release прошла без предупреждений. 18 целевых интеграционных тестов прошли на PostgreSQL 17, включая английский старт, mixed-ввод, отказ планировщика, перезапуск, подтверждённую смену цели, повторы и защиту от потери критерия при откате.
- Язык начальных сообщений определяется исходной целью. При оценке провайдер получает указание сохранять язык материала независимо от языка ответа. Запрос объяснить на другом языке действует для текущего пояснения. Пользовательская сквозная проверка языка и качества с подключённой моделью остаётся открытой.
- Для live-качества, Telegram Desktop и NVDA требуются отдельные прогоны.
