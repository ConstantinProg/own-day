# Адаптивные тестовые упражнения

Вопрос с выбором ответа использует обычный `Lesson` и ограничение на одно активное
упражнение. PostgreSQL хранит снимок опубликованного вопроса, ревизию кнопок,
черновик, подсказки и историю попыток. Старые упражнения читаются с пустыми
полями выбора.

Для первого короткого знакомства с темой наставник может выбрать один вариант,
для различения знакомых признаков — несколько, а при повторяющихся затруднениях —
«Верно / Неверно». Цель, стратегия обучения, диагностические наблюдения и
история навыка передаются генератору. Проверка понимания после теста, углублённое
упражнение, проверка переноса, работа над проектом и интервальное повторение
используют открытые вопросы. Предметная диагностика и её правила сохранены.

Генератор за один вызов предлагает объяснение, вопрос с ключом и запасное
открытое упражнение по одной идее. Уровень, цель и практическое применение
задают сложность и пример. В занятии по маршруту ученик сначала видит
объяснение и открывает сохранённый вопрос действием «К упражнению».
При подтверждённом владении навыком вопрос может открыться сразу.
Структура проверяется в коде. Модель
повторно выводит ключ и отмечает неоднозначность в том же ответе. Это самопроверка
модели. Если она выявила расхождение или ограничение, используется открытый вариант.
Темы, для которых задействован адаптер источника, идут через существующий путь
проверки. Для остальных тем генератору разрешены только самодостаточные ситуации
и устоявшиеся принципы. Истинность утверждений без проверяемого источника
остаётся ограничением.

Ключ сравнивается с множеством выбранных вариантов. Для частичного результата
в наборе есть верный вариант и выбраны не все варианты вопроса. После первого
промаха возможна одна повторная попытка и максимум одна подсказка. Подсказка
предлагает сверить варианты с условием. Полное решение доступно через
«покажи решение», а разбор завершённых попыток — через «почему такая оценка».
Ответ после решения, подсказки, повтора или повторного
предъявления того же вопроса учитывается как ответ с помощью.

Завершённый тест сохраняет одно Evidence, связанное с уроком. Его характеристика
Recognition не повышает Mastery, не удлиняет интервалы и не закрывает тему
маршрута. Первая самостоятельная ошибка остаётся видимой после исправления.
Далее наставник предлагает новый открытый вопрос по теме или открытое отложенное
повторение. Проверка понимания требует задания на объяснение или сравнение.
Следующий вопрос выдаётся по ответному действию пользователя.

Контекстные кнопки используют общий подписанный формат. Для теста кнопка
содержит идентификатор урока, версию, ревизию, действие и идентификатор варианта.
После сохранения входящего события Telegram получает подтверждение приёма.
Worker проверяет владельца и версию, затем атомарно сохраняет выбор или
попытку, намерение для outbox и результат обработки. Переключение обновляет
только клавиатуру исходного сообщения. При двух нажатиях с одной ревизией
второе получает сообщение об устаревшей кнопке. Для нескольких вариантов
«Ответить» появляется после первого выбора. Можно также отправить буквы
вариантов через запятую. Если набор букв недопустим, бот снова показывает
варианты и предлагает исправить ввод. После перезапуска «Продолжим» показывает
сохранённый вопрос и выбор. Первое нажатие после окончания учебной сессии
восстанавливает вопрос и обновляет клавиатуру. Ответ принимается со свежей
клавиатуры.

Миграция `20261120110000_AddAdaptiveChoiceExercises` сохраняет снимки тестов.
Миграция `20261120120000_AddTelegramKeyboardEdits` добавляет редактирование
клавиатур. Ранее принятые `learning_choice` v1 запросы обрабатываются после
обновления. Старые неподписанные кнопки предлагают открыть текущий вопрос
через «Продолжим». Для отката см. [совместимость очереди](request-processing.md).

## Ручная приёмка с NVDA

Ручная проверка пока не выполнена. Используйте тестового бота с включённой
очередью Learning, Telegram Desktop и NVDA на Windows.

Для подготовки используйте фиксированные задания из [приёмочных тестов](../../../tests/OwnDay.IntegrationTests/Telegram/PostgresAdaptiveChoiceTests.cs).
Сценарий выбора формата задаёт три состояния навыка в тестовой базе: новая
тема, ранее полученный верный ответ и две самостоятельные ошибки. Начните
упражнение командой `/learn_next` в каждом из этих состояний.

1. Откройте вопросы всех трёх форматов. Клавиатурой перейдите
   к вариантам. Проверьте чтение текста, букв и названий кнопок.
2. В вопросе с несколькими вариантами нажмите кнопку и проверьте чтение слов
   «выбрано» и «не выбрано» на обновлённых кнопках. Снимите последний выбор
   и проверьте, что «Ответить» исчезла, а текст вопроса сохранился.
3. Выберите два варианта, перезапустите приложение и напишите «Продолжим».
   Проверьте восстановленный выбор. Нажмите старую кнопку и проверьте чтение
   сообщения об устаревшей версии. Завершите ответ на свежей клавиатуре.
4. Ответьте на следующий тест буквами без кнопок. Сделайте ошибку, прослушайте
   подсказку и повторите попытку. Проверьте чтение объяснения и перехода к
   открытому вопросу.
