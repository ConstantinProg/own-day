# Первый урок

В личном чате Telegram: `/learn <тема>` создаёт короткий урок с одним вопросом; `/answer <ответ>` сохраняет ответ и оценку AI, завершая урок. Новый `/learn` при незавершённом уроке повторяет текущий материал. Ответ другого пользователя не получает доступ к уроку. Материал генерируется на языке темы. Оценка AI не является подтверждением освоения навыка.

Примените миграцию `202611050001_AddLearningLessons` обычным механизмом миграций приложения. Используются существующие `InboxAnalysis:OpenAI:Enabled`, `ApiKey`, `Model`, `MaxOutputTokens`, `TimeoutSeconds`. Ключ задаётся через runtime configuration. Невалидный материал и ошибка провайдера не создают урок и не завершают текущий; повторите команду новым сообщением.

Урок, результат, обработанный update и исходящее сообщение фиксируются одной транзакцией; PostgreSQL advisory lock сериализует операции пользователя. После перезапуска `/learn <тема>` возвращает незавершённый урок. Повторная доставка update после фиксации не вызывает LLM повторно. При откате вызов LLM может повториться. Доставка использует существующий outbox.

Ограничения: генерация выполняется внутри webhook и удерживает транзакцию до ответа LLM с ограничением времени. Фоновая генерация отсутствует. Учебные вызовы не включены в ledger стоимости inbox; длительность, модель и расход токенов успешных вызовов записываются в Serilog без содержимого и ключей, денежная стоимость не вычисляется. Поддерживаются явные команды без распознавания свободного запроса. Пауза, уточнения, программа и модель знаний относятся к следующим этапам. Управляющие сообщения пока на английском.
